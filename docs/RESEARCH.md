# 研究协议

在首个冻结因子组合完成至少三个月真实前向 Paper 并取得正成本后超额之前，不增加流程、审批、LLM 角色或页面；恢复旧链路还须单独人工评审。现有两策略的拒绝结论保留，不降低门槛、不晋级。

## Loop 顺序

1. 先固定假说、方向、股票池、窗口、费用、期限和风险约束。已看结果的窗口不再称独立样本外。
2. 检查真实交易日和覆盖。按当时上市时长、ST、停牌和流动性建池，不使用今天的明星蓝筹名单。
3. T 收盘可见信息计算因子；同一横截面 MAD 去极值、标准化。完整历史行业/市值到位后才中性化。
4. 标签为 T+1 开盘进入、T+h+1 开盘退出。先补齐交易日网格再位移，不能删除停牌行后把下次成交当次日。
5. 输出 IC/RankIC、五分层、双边 L1 换手、1/5/20 日衰减和成本代理。固定日历步长取不重叠持有期；已选股票任一缺收益则整组记为不完整，不删掉失败股票后重选。
6. 执行前登记，成功/失败均留账。同规格重跑是新 attempt，不虚增独立参数试验；新参数/窗口/代码/数据版本为新规格。
7. 固定参数后滚动训练/测试，隔离期至少 horizon+1 个交易日。约束行业、市值、贝塔、TE、个股主动权重和换手；优化不可行直接拒绝。
8. 接入既有 A 股撮合，计算真实基准下净超额、IR、TE，记录拒单/费用/滑点/退市处置。纯前向从冻结后的实际自然交易日开始。

## 当前能力和限制

已运行：5 日反转、20 日低波动、异常成交额（成交额相对 20 日均值，尚非自由流通股本换手率因子）。财务计算 API 包含 EP/BP/ROE/经营现金流/营业利润比/负对数市值，但需要可见财务面板。行业/市值中性化为显式 API；价量 Loop 缺相关数据，未声称已应用。分析师预期调整未实现。

当前研究使用每月首个真实交易日的历史流动性池，月内继续检查 ST/停牌，不是中证 500 成分股回测。专业数据面板 API 已实现，但尚未与整个研究命令在真实数据上接通。

旧海龟 E1–E18 加 12 组网格至少 30 次试验；新台账不能取代缺失历史。DSR 只使用真实同窗口月度夏普分布；结果不足、零方差或月份不足直接拒绝，不用扰动方差补齐。DSR 仍为近似，不能解决相关试验和低统计功效。

价量结果是诊断，缺失整组的排除仍可能有选择偏差；尚无实际成交、指数权重、中性化、完整风险模型的收益验证。不得据此宣称盈利或启动 Paper。完整 walk-forward 拟合、专业源同步、组合接入 Paper 和三个月前向验收仍未完成。
