# GOAL — 个人 A 股量化闭环环境

> 版本 v1.0 · 2026-08-22 · 状态：已批准

## 一句话目标

在本地搭建一个**闭环、可迭代、可审计**的个人 A 股量化环境：
数据 → 策略 → 回测 → Paper 交易 → 总结回顾，以 **Loop Engineering** 模式持续运转，
每次迭代的进展都记录到 `AGENT.md`。

## 目标分解（SMART）

| 编号 | 目标 | 验收标准 |
|------|------|---------|
| G1 | 数据自给 | 本地拥有全 A 股日线数据，一键更新，新鲜度可查询 |
| G2 | 策略可注册 | 策略以文件形式注册，含参数、状态（研究/候选/上线/下线） |
| G3 | 回测有门禁 | 策略只有通过回测门禁（夏普/回撤阈值）才能进入 paper |
| G4 | Paper 全自动 | 每日根据上线策略生成目标持仓，模拟成交，记台账（SQLite） |
| G5 | 复盘成文 | 每次 loop 生成复盘报告，进展写入 AGENT.md |
| G6 | 控制台可视 | 本地 Web 控制台展示各阶段内容、执行状态、净值曲线 |
| G7 | Loop 可调度 | 整条流水线一条命令跑完，可挂定时任务 |

## 非目标（明确不做）

- ❌ 实盘下单（paper 阶段为止；实盘需另立项目评审）
- ❌ 高频/分钟级策略（日线级别）
- ❌ 多账户/组合优化器（v1 单策略单账户）

## 参考范式

TradingAgents（多智能体模拟投资公司）：分析师团队 → 多空研究辩论 → 交易员 → 风控 → 基金经理。
v1 用**确定性代码**实现同等分工（见 ARCHITECTURE.md 角色映射），LLM 智能体版本列入 Phase 3。
