# 已有持仓的跨日 Paper 保护

## 适用范围

`existing_position_stop.v1` 只用于独立 gate/no_gate Paper 账户的既有持仓。
这是完成交易日后的日线撮合模型，不是交易所驻留订单、实时盯盘服务或 Live 授权。
买入提案中的 `stop` 仍是风险参考；没有显式 `protection` 就没有跨日保护。

本轮不支持买入成交后自动挂保护、止盈/追踪止损、部分批次保护或自动滚动延期。
不为旧账户追补保护，不修改历史计划、审批或成交。

## 指令契约

交易员提出、风险经理逐条审核，再由当前 Paper 自动审批绑定 `plan_hash`。
建立和替换只能附在持有意图上，`position_pct=0`，无买入价、DAY 退出或附加条件。

```json
{
  "code": "600036",
  "direction": "持有",
  "position_pct": 0,
  "entry": null,
  "protection": {
    "action": "create",
    "expected_order_hash": null,
    "type": "stop",
    "price": 9.30,
    "qty": "all_existing",
    "valid_until": "2026-09-30"
  }
}
```

- `create`：当前不得已有保护，预期版本必须是 null；无持仓记录 `no_position`，不预挂未来买入。
- `replace`：字段与 create 相同，预期版本改为当前完整64位 `order_hash`；重新绑定当时的全部批次。
- `cancel`：只允许 `action` 和 `expected_order_hash` 两个字段；可附在持有或显式 DAY 卖出/减持意图上。
- 有效期包含结束日，最长为建立/替换日后30个自然日；价格必须是有限正数，精度0.01元。
- 旧版本撤销/替换记录 `stale_version`，原保护不变；风险否决当前指令也不撤销旧保护。
- 保护存续时，同标的其他交易必须显式撤销。可以撤销与 DAY 退出同条提交，避免猜测盘中先后。

`order_hash` 绑定原计划版本、标的、建立/替换日期和指令，表示授权指令的版本。
双账户同一指令可有相同版本，实际数量/批次分别绑定在各自回执中。
它不是不可伪造的签名，也不证明历史发布时间或策略收益。

## 跨日规则

每次正常结算从既有回执重建状态，不新增可独立修改的保护订单表。
保护固定建立/替换时的全部股数和批次，不扩大到后续买入，也不自动缩成可卖数量。
整仓包含 T+1 冻结股则拒绝当日卖出并保留保护；全部可卖后再按当天行情评估。

执行仍调用 `simulate_exit`：未触价为 `unfilled`；停牌、跌停等拒绝不会虚构成交。
跳空跌破按开盘及不利滑点模型撮合，不保证止损价。成交后终止，过期后记录 `expired`。
日会未再次提及不撤销原授权；但缺少正常日计划、会话、原授权来源或行情时不能继续执行。

原计划内容改变、审批版本不符、回执丢失/损坏、批次失配会失败关闭。
活跃保护不能跳过中间交易日；参考前收与前次收盘不连续也会阻断，避免把未建模公司行为算成止损亏损。
这不构成公司行为处理：分红、送转、拆并股仍需单独实现和验证。

## 审计与恢复

每份新结算回执保留原始候选、期初/期末保护状态、创建/替换/撤销/到期事件、当日撮合结果。
账户结算注记标明保护政策，防止保护回执被删后静默变成“没有保护”。
这些记录与委托、成交、批次、估值一起在单账户事务内提交；故障时一起回滚。
双账户仍使用既有互斥及幂等恢复机制，不宣称两个独立数据库具有单事务原子性。

公开执行入口在任一账户写入前检查双方历史来源、活跃批次、连续会话和参考价格。
来源核验回读原日 `plan.json` 和 `paper_decision.json`，不能仅凭回执自洽授予卖出权限。
日常收尾缓存也复核此链路。独立审计会使用原始行情重放，并保留历史缺证，不补签。

完整工作流备份保存计划、决策、运行账本和 Paper 回执；只能恢复到新隔离目录。
恢复后先只读核验原版本，再恢复原任务。仅拷贝账户数据库不足以恢复来源授权。
任何运行环境恢复、生产激活和外部副作用仍遵守 [WORKFLOW_RECOVERY.md](WORKFLOW_RECOVERY.md)。

## 展示与反事实

`/api/paper-state` 的 `protection` 包含最近结算日、活跃订单版本、数量、价位、有效期和最近事件。
`matched_receipts` 只代表回执投影核验，不代表来源授权、前向发布时间或真实成交认证。
坏回执显示 `unverified`、`active=null`，不能显示成空列表。原计划授权另见历史审计。

交易员和风险经理均得到批次和保护版本快照；LLM只能提出/审核指令，无权直接写账户。
本地 Multica Runbook 已同步契约，不代表远端同步、角色 Run 或真实定时闭环已通过。

连续反事实沿用相同生命周期。单日重置诊断无法重建跨日状态，遇保护指令返回
`requires_continuous_state`，组合权益和收益未知，不给出零收益。
任何受控夹具收益都不是策略绩效。
